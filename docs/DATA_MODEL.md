# Data model

The diagram below is the full Prisma schema rendered as an entity–relationship diagram. It is generated with [prisma-erd-generator](https://github.com/keonik/prisma-erd-generator) whenever you run `npx prisma generate` (see the `generator erd` block in `prisma/schema.prisma`). The SVG file lives next to this page as `data-model-erd.svg`.
